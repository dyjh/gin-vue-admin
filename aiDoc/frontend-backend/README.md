# Frontend Backend

这个目录用于存放前后端协作边界与前端开发规范。

适合记录：

- API 归属边界
- 请求与响应结构
- 字段名与类型约束
- 联调注意事项
- 前端代码与样式规则
- 工具函数复用约束

当前已拆分出的核心说明：

- `boundary.md`
- `frontend-rules.md`
- `frontend-utils.md`
- `order-food-contract-baseline.md`：“来干饭”小程序、Go 后端与后台 Web 的状态、字段、认证、分页和幂等基线。
- `order-food-admin-api-contract.md`：“来干饭”后台管理端的错误码、幂等、指标、权限和高风险工作流。
- `miniapp-auth-capability-compliance.md`：微信自动登录、平台整体能力开关、积分联动及小程序发布包零敏感字样规则。
